# Fritz.Wulf GitHub Pages

Public gateway for the Fritz.Wulf ecosystem.

- Root: `https://fritz-wulf.github.io/`
- Repository browser: `https://fritz-wulf.github.io/repo/`
- Machine index: `https://fritz-wulf.github.io/repo/index.json`
- Package manager: `https://github.com/Fritz-Wulf/fw`

The root page consumes the repository index read-only for live package/version status. Package metadata remains owned by `Fritz-Wulf/repo`.
